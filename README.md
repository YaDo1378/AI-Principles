# Codex 관리자 기준점

이 폴더 하나를 Codex 관리자 원칙, 인수인계, 보조 스크립트의 기준점으로 쓴다.

## 먼저 볼 파일

1. `관리자_인수인계.md`
2. `대원칙.md`
3. `WORKER_SUPERVISOR_GUIDE.md`
4. 필요한 경우 `_docs` 안의 공지 문서

## 운영 기준

- 관리자 문서와 전역 원칙은 이 폴더에서 관리한다.
- 각 컴퓨터의 실제 사용자 경로는 다를 수 있으므로 문서에는 가능하면 `%OneDrive%\Codex` 또는 `OneDrive의 Codex` 기준으로 적는다.
- 대화 원문은 기억 기록 체계 이전의 임시 백업 대상이었고, 현재는 OneDrive `Codex`에 백업하지 않는다.
- GitHub는 이 폴더의 민감하지 않은 원칙, 문서, 스크립트를 공유하는 원격 기준점으로 쓴다.

## GitHub 업로드 기본 포함

- `대원칙.md`
- `관리자_인수인계.md`
- `WORKER_SUPERVISOR_GUIDE.md`
- `README.md`
- `_docs`
- `_internal`
- `_tools`
- `처음설정.cmd`

## GitHub 업로드 기본 제외

- 대화 원문, 대화 백업, 세션 로그, 대화 상태 파일
- 컴퓨터별 충돌 파일
- 민감 정보가 들어갈 수 있는 임시 산출물
